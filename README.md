# voidOS

My personal life operating system: one place to capture everything on my mind and turn it into clear next steps.

## Why

Tools like Notion, ClickUp and TickTick are built for teams and stuffed with features I don't need, and they keep pushing upgrades. voidOS is built for one person: me. It stays simple, low-friction, and works with my brain instead of demanding discipline.

## How it works

It follows GTD (Getting Things Done):

- **Capture** anything into the Inbox, fast.
- **Process** the Inbox: each item becomes a next action, a project, or gets deleted.
- **Do** from a list of concrete next actions only.

Claude can manage it too, so I can add and check things just by asking.
